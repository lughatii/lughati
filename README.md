# لُغتي — موقع تعلّم اللغات

موقع عربي متجاوب لتعلّم الإنجليزية والألمانية، يعمل دون حساب أو خادم.

## المميزات
- مكتبة كلمات وجمل مع ترجمة عربية ونطق تقريبي مكتوب وأمثلة.
- نطق صوتي عبر Speech Synthesis حسب الأصوات المتاحة في المتصفح والجهاز.
- كروت حفظ مع كشف الإجابة وتسجيل الكلمات التي تمت مراجعتها.
- اختبارات اختيار من متعدد ونقاط XP ومستويات.
- مفضلة وسلسلة أيام، مع حفظ التقدم في LocalStorage.
- تصميم متجاوب للموبايل والكمبيوتر.

## النشر عبر GitHub Pages
1. افتح Settings في المستودع.
2. اختر Pages من القائمة.
3. في Build and deployment اختر Deploy from a branch.
4. اختر الفرع `main` والمجلد `/(root)` ثم Save.
5. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## ملاحظات
- المحتوى الحالي مجموعة بداية قابلة للتوسعة، وليس قاموسًا شاملًا.
- النطق المكتوب بالعربية تقريبي.
- التقدم محفوظ على هذا المتصفح فقط؛ مسح بيانات الموقع قد يحذفه.
